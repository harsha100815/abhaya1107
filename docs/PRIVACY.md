# Privacy and safety principles

ABHAYA uses temporary, explicit sharing:

- Location sharing is off by default.
- A journey or emergency session must be started by the user before live location updates.
- A safety timer is a reminder/escalation workflow; it does not continuously track location.
- Camera and microphone are requested only after the user chooses evidence mode.
- Public share links show first name, state, minimal last-known location, and timestamp only.
- Public links expire, can be revoked, and never include medical notes or account identifiers.
- Retention settings are stored per user and should be enforced by production workers.
- Users can end sessions, revoke links, remove contacts, and delete history where law and storage constraints allow.

Legal review placeholders:

- Consent wording and age/guardian requirements.
- India-specific personal data, health data, communications, and emergency-service rules.
- Data-processing agreements with push, SMS, email, maps, storage, and analytics vendors.
- Data subject rights, deletion/retention schedules, grievance handling, and breach notification.
- Workplace/education usage and trusted-contact consent.

The product must never be marketed as a guarantee of safety. Any anomaly detector should be described as a configurable request for confirmation; it must not label a person as being in danger based solely on GPS.
